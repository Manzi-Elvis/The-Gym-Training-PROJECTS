Flexbox Concepts

Each concept controls either the parent container or the child items.

display: flex

Turns the parent into a flex container. Direct children become flex items.

.container { display: flex; }

flex-direction

Chooses the main axis: row, column, row-reverse, or column-reverse.

flex-direction: row;

justify-content

Moves items along the main axis.

justify-content: center;

align-items

Moves items along the cross axis.

align-items: center;

align-self

Lets one child ignore the parent's alignment.

.item { align-self: flex-end; }

flex-wrap + gap

Allows items to move to the next line and creates clean spacing.

flex-wrap: wrap; gap: 20px;

flex-grow

Controls how much an item expands when there is extra space.

flex-grow: 1;

flex-shrink

Controls how much an item shrinks when space is tight.

flex-shrink: 0;
